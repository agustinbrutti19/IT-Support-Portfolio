# KB-002 — Microsoft 365 Login Issues

**Category:** Account / Authentication  
**System:** Microsoft 365 
**Audience:** Helpdesk  
**Severity:** Medium  
**Last Updated:** 2026-10-06

## Problem

Users may be unable to sign in to Microsoft 365.

The issue may prevent access to services such as Outlook,
Teams, OneDrive or other Microsoft 365 applications.

## Symptoms

- The user is unable to complete the Microsoft 365 sign-in process.
- An error message may be displayed during authentication.
- The user may be repeatedly prompted to enter their credentials.
- The user may be unable to access one or more Microsoft 365 services.
- Other users may or may not be affected by the same issue.

## Troubleshooting Steps

1. Confirm the exact error message displayed during sign-in.
2. Verify whether the issue affects only the user or multiple users.
3. Confirm that the user is using the correct Microsoft 365 account.
4. Verify that the user's account is active and not disabled.
5. Confirm that the user can access other services or applications normally.
6. If applicable, verify whether the user can authenticate using a different browser or device.
7. Check whether the user is being prompted for multi-factor authentication (MFA).
8. If MFA is involved, confirm whether the user can complete the authentication challenge.
9. Verify whether there are any known Microsoft 365 service issues affecting the organization.
10. If the issue is isolated to the user's account, continue with account-specific troubleshooting.
11. If multiple users are affected or a service issue is suspected, document the evidence and escalate appropriately.

## Common Causes

Common causes of Microsoft 365 login issues include:

- Incorrect username or password.
- Account locked or disabled.
- Expired credentials.
- Multi-factor authentication (MFA) problems.
- Incorrect MFA method or unavailable authentication device.
- Browser session or cached credential issues.
- Problems with the user's device or network connection.
- Microsoft 365 service disruptions.
- Conditional Access or security policies preventing authentication.
- Incorrect account configuration.

## Resolution

The resolution depends on the identified cause.

Possible resolutions include:

- Correcting invalid or outdated credentials.
- Unlocking or re-enabling the user's account when appropriate.
- Updating or resetting the user's authentication method.
- Resolving MFA-related issues.
- Clearing browser sessions or cached credentials when appropriate.
- Testing access from a different browser or device.
- Resolving device or network-related issues.
- Waiting for or escalating an organization-wide Microsoft 365 service issue.
- Reviewing account configuration or security policies when required.

After applying a resolution, Helpdesk should verify that the user
can successfully sign in and access the required Microsoft 365
services.

## When to Escalate

The issue should be escalated when:

- The user's account is active and the credentials are confirmed
  to be correct, but authentication continues to fail.
- MFA cannot be restored through standard Helpdesk procedures.
- Multiple users are experiencing the same authentication issue.
- A Microsoft 365 service disruption is suspected.
- Conditional Access or other security policies may be blocking
  authentication.
- The issue requires administrative privileges or configuration
  changes outside the Helpdesk's standard permissions.
- The problem persists after standard troubleshooting has been
  completed.

## Information Required for Escalation

The following information should be collected before escalating
a Microsoft 365 authentication issue:

- User name and department.
- Ticket number.
- Microsoft 365 account affected.
- Exact error message displayed.
- Date and approximate time when the issue occurred.
- Microsoft 365 service or application affected.
- Whether other users are experiencing the same issue.
- Device and operating system.
- Browser or Microsoft 365 application being used.
- Network environment, if relevant.
- MFA status and any authentication errors observed.
- Troubleshooting steps already performed.
- Results of each troubleshooting step.
- Any relevant screenshots or error information.
- Business impact of the issue.
